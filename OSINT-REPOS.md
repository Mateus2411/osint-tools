# 🔍 Lista de Repos de OSINT (GitHub)

Curadoria de repositórios para **OSINT pesado** — desde os clássicos usados por todo mundo até projetos conhecidos em comunidades mais fechadas (r/osint, fóruns de CTI, listas *awesome*). Pesquisa feita em 21/09/2026.

✅ **Só ferramentas 100% gratuitas / open source.** Nenhum serviço pago entrou nesta lista. Ferramentas com versão comercial *opcional* (como SpiderFoot HX ou a nuvem do ProjectDiscovery) estão marcadas com 🆓, mas a versão do repositório é livre e funcional sem pagar nada.

> ⚠️ **Aviso:** use apenas para fins legítimos de pesquisa, segurança defensiva e investigação autorizada. Respeite leis de privacidade (LGPD/GDPR) e os Termos de Serviço das plataformas.

| Repo | Descrição |

| [ffuf/ffuf](https://github.com/ffuf/ffuf) | Fuzzuf — fuzzer ultrarrápido de URLs/palavras-chave em Go. |
| [s0md3v/XSStrike](https://github.com/s0md3v/XSStrike) | XSStrike — detecção e fuzzing de XSS inteligente. |
| [projectdiscovery/katana](https://github.com/projectdiscovery/katana) 🆓 | Katana — crawler/fuzzer de URLs (next-gen). |
| [lazzzaroni/... ] *(verifique)* — [dirsearch](https://github.com/maurosoria/dirsearch) | Dirsearch — brute force de diretórios e arquivos. |
| [OJ/gobuster](https://github.com/OJ/gobuster) | Gobuster — enumeração de dirs, DNS e vhosts em Go. |
| [s0md3v/Arjun](https://github.com/s0md3v/Arjun) | Arjun — descoberta de parâmetros HTTP ocultos. |
| [wpscan/wpscan](https://github.com/wpscan/wpscan) | WPScan — scanner de vulnerabilidades para WordPress. |
| [zaproxy/zaproxy](https://github.com/zaproxy/zaproxy) | OWASP ZAP — proxy de interceptação / scanner web (alternativa open source ao Burp). |
| [rapid7/metasploit-framework](https://github.com/rapid7/metasploit-framework) | Metasploit — framework de exploração (o maior do mundo). Pesarão, mas é referência. |
