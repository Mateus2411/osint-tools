## What it is

Guided social-engineering vector framework for authorized red teams:
phishing, credential harvester, payloads, PowerShell, Fast-Track and more.
Runs via **WSL2 Ubuntu** (Python 3.12): `run-setoolkit.bat` or

```powershell
wsl -d Ubuntu -- bash -lc "cd /home/keila/setoolkit && sudo /home/keila/.venvs/setoolkit/bin/python /home/keila/setoolkit/setoolkit"
```
